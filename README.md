# Datheon Python Programming Internship

## Overview
This repository contains three Python projects completed as part of the Datheon Python Programming Internship. Each task focuses on practicing Python fundamentals through practical applications.

## Tasks

### Task 1: Hangman Game
A terminal-based word guessing game where players guess a hidden word within a maximum of six incorrect attempts.

**Features:**
- Random word selection
- Hidden word display
- Tracks guessed letters
- Six incorrect attempts
- Win and lose conditions

**Modules:** `random`

### Task 2: Stock Portfolio Performance Tracker
A Python application that calculates stock portfolio performance using stock prices stored in a CSV file.

**Features:**
- Stock information input
- Investment and market value calculation
- Profit/loss and percentage return
- Overall portfolio summary
- CSV report generation

**Modules:** `csv`

### Task 3: File Organizer
A Python application that automatically organizes files into separate folders based on their file extensions.

**Features:**
- Automatic file classification
- Folder creation
- File movement
- Duplicate filename handling
- Error handling

**Modules:** `os`, `pathlib`, `shutil`

## Technologies Used
- Python 3
- VS Code
- CSV and text file handling
- Python standard libraries

## Learning Outcomes
- Practiced Python programming fundamentals.
- Worked with lists, dictionaries, loops, and functions.
- Learned file and directory management.
- Practiced exception handling and input validation.
- Built practical projects using Python.
