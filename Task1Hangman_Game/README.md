# Hangman Game

A command-line word guessing game developed using Python. The program randomly selects a word from an external text file, and the player must guess the word one letter at a time within a limited number of attempts.

### Features
- Random English word selection.
- Letter-by-letter guessing.
- Tracks correct and incorrect guesses.
- Visual Hangman stages.
- Six maximum incorrect attempts.
- Win and lose conditions.

### Technologies
- Python 3
- Random module
- File Handling
- Lists and Sets
- Loops and Conditional Statements

### How to Run
```bash
python main.py
```

### Learning Objectives
This project demonstrates basic Python programming concepts, including file handling, random selection, sets, loops, conditional statements, and string manipulation.
